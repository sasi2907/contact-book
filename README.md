# Contact Book

A simple command-line Contact Book application built with Python.

Stores the contact information in a List and retrive when user ask for the contact.

## Features

- Add new contacts
- View all contacts
- Search contacts by name
- Update contact information
- Delete contacts
- Input validation
- Menu-driven interface

## Contact Information

Each contact contains:

- Name
- Phone number
- Email address


## How to Run

Make sure Python is installed, then run:

python contact_book.py


## Note:
- Still database and GUI interface is not integrated so perment storing of contact details is not possible.
